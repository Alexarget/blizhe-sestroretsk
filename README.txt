БЛИЖЕ. СЕСТРОРЕЦК — ВЕРСИЯ 1.1 — DIGITAL-ЖУРНАЛ + КАТАЛОГ

Состав:
index.html — основная страница
styles.css — оформление
app.js — фильтр категорий, карточки, ссылки
 data.js — ТОЛЬКО ЗДЕСЬ редактируйте мастеров

Открыть локально:
1. Распакуйте архив в одну папку.
2. Откройте index.html в браузере.
3. Выберите категорию.

Как добавить мастера:
1. Откройте data.js текстовым редактором.
2. Скопируйте один блок { ... } из массива window.BLIZHE_MASTERS.
3. Измените id (уникальный), name, service, category, description, area, price.
4. В image вставьте публичную ссылку https://... на фото или оставьте ''.
5. В contactUrl вставьте согласованную ссылку на VK/Telegram или оставьте ''.
6. Сохраните файл и обновите страницу.

Категории для поля category:
auto — Автоуслуги
remont — Дом и ремонт
beauty — Красота и уход
food — Еда и кондитерские
photo — Фото и творчество
fitness — Фитнес

https://ВАШ-АДРЕС-САЙТА/?category=remont
https://ВАШ-АДРЕС-САЙТА/?category=beauty

ВАЖНО:
- Адреса выше условные; пока сайт не опубликован в интернете.
- Карточки заполнены только известной из переписки информацией. Уточните данные у исполнителей.
- Контакты и фотографии мастеров размещайте с их согласия.
- VK может ограничивать внешние ссылки; проверьте открытие после публикации.
- Для первой версии достаточно статического хостинга, например GitHub Pages или Netlify.
